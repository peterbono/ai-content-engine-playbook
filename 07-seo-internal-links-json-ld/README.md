# 07 · SEO, internal linking & JSON-LD

**Time:** 30 min · **You'll build:** a JSON-LD builder derived from the HTML, an internal-link integrator with caps and anchor validation, and an indexing ping with a quota guard.

## 🎯 Goal

Ship the technical SEO plumbing automatically, so that every published article has valid structured data, a sane number of internal links, and gets submitted for crawling.

## What FlashVoyage did

| Concern | Where |
|---|---|
| JSON-LD (Article, FAQPage, BreadcrumbList, TravelAction) | `seo-optimizer.js`, injected into `<head>` by a small WordPress plugin through a post meta field |
| Internal link selection | `internal-links-manager.js` (top 3 relevant articles), `contextual-link-integrator.js` (hard cap of 15 per article) |
| Anchor sanity | `anchor-text-validator.js` |
| Editorial KPIs before publish | `quality-analyzer.js`, including "internal links >= 3" |
| Indexing | `scripts/auto-index-modified.mjs`, daily cron, logs to `data/gsc-indexing-log.jsonl` |

## 🧠 The design decision: derive structured data from the rendered HTML

The FAQ schema is not generated by a separate prompt. It is **parsed out of the final HTML**, so the schema can never claim a question the page does not show. If a FAQ heading exists but no question/answer pair can be extracted, the builder logs a warning instead of inventing one.

## 🧩 Code: FAQPage from the page itself

From `seo-optimizer.js` (trimmed):

```js
const faqHeading = /<h[23][^>]*>(?:FAQ|Questions?\s+fr[ée]quentes?)[^<]*<\/h[23]>/i;
if (faqHeading.test(html)) {
  const items = [];
  // Format A: heading or bold question followed by a paragraph
  for (const m of html.matchAll(/<(?:h[34]|strong|b)[^>]*>([^<]{10,200})\?<\/(?:h[34]|strong|b)>\s*(?:<[^>]+>\s*)*<p>([^<]{20,1000})<\/p>/gi))
    items.push({ '@type': 'Question', name: m[1].trim() + '?', acceptedAnswer: { '@type': 'Answer', text: m[2].trim() } });
  // Format B: <details><summary>Q</summary><p>A</p></details>
  if (!items.length)
    for (const m of html.matchAll(/<details[^>]*>\s*<summary>([^<]{10,300})<\/summary>[\s\S]*?<p>([^<]{20,2000})<\/p>[\s\S]*?<\/details>/gi))
      items.push({ '@type': 'Question', name: m[1].trim(), acceptedAnswer: { '@type': 'Answer', text: m[2].trim() } });

  if (items.length) schemas.push({ '@context': 'https://schema.org', '@type': 'FAQPage', mainEntity: items });
  else console.warn('FAQ heading found but no extractable Q/A pair');
}
```

The same file builds `Article`, `BreadcrumbList`, and a `TravelAction` (from France to the destination) when a destination was identified. The GEO phase later added HowTo, Place/TouristDestination and Product/Offer schemas (see [module 08](../08-geo-answer-engines/)).

A standalone builder is in [`templates/json-ld/`](../templates/json-ld/).

## 🧩 Code: anchors that are actually words

From `anchor-text-validator.js`. Anchors are produced by code and LLMs, and both can produce garbage, so the validator rejects anything that looks like a widget fragment, a URL or markup:

```js
this.validPattern = /^[\p{L}\p{M}\p{N}\s'’\-.,:;!?()]+$/u;
this.invalidPatterns = [
  /\b(https?:\/\/|www\.)/i,   // URLs
  /[<>{}[\]]/,                // markup or code
  /\d{10,}/,                  // long digit runs
];
this.forbiddenWords = ['comparer les prix', 'script', 'charset', 'utf-8', 'target', 'href'];
```

## 🧩 Code: indexing with a quota guard

From `scripts/auto-index-modified.mjs` header: pick every post modified in the last 26 hours (small overlap with the previous run), cap at 100 URLs per run because the API quota is 200 per day, support `DRY_RUN=1`, and append one JSON line per attempt to a log. The archive holds 105 such log lines, all with result `ok`.

## ⚠️ Pitfalls Florian actually hit

1. **`ok` is not "indexed".** A successful submission only means the request was accepted. Also note that Google documents its Indexing API for job-posting and livestream pages, not for blog articles. Measure indexing in Search Console coverage, not in your submission log.
2. **Pruning is part of SEO.** On 2026-04-24, a reset the project calls "Plan C" deleted 30 near-duplicate articles, added 29 permanent redirects, and inserted 83 internal links (project brief in the dashboard repo). The site went from 140 articles in an April crawl to 38 live articles at archive time. Publishing at volume and deleting later costs more than not publishing duplicates in the first place.
3. **The CDN can undo all of it.** A Cloudflare rule returned 503 to Googlebot until a fix on 2026-05-03 (workflow comment). Perfect markup does nothing if crawlers get an error. Test with a crawler user agent after every infrastructure change.

## ✅ Checklist / exercise

- [ ] Generate JSON-LD from your rendered HTML. Validate it with a schema validator in CI.
- [ ] Add an internal-link cap and an anchor validator. Run them on 10 existing articles; count rejects.
- [ ] Build a daily "modified in the last 26 hours" indexing or sitemap ping with a hard cap and a dry run.
- [ ] Check what a crawler sees: `curl -A "Googlebot" -I https://your-site/` should return 200.
- [ ] Audit bylines: every author on your site should be a real, reachable person or the brand.
